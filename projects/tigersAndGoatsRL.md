Tigers and Goats is an ancient game in which two players, one controlling the tigers and the other the goats, compete to accomplish different win conditions. There are a few different variations with different board types, but we settled on the non-square version as shown below.

Initially the project had a goal of employing reinforcement learning (RL) to build dynamic weather and power forecasting but over time we decided to focus on games to get experience in using RL for problems with clear acrions and results. RL has been used to train agents in other games so this was a natural shift. 

This project is a VIP (vertically integrated project) which means that students of different class standings work together and the project itself takes more than one semester. Since reinforcement learning (RL) can be quite complex this proved to be ver beneficial.
